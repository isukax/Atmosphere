# 検証結果

2026-10-21、AMD Radeon RX 7800 XT、MSVC 19.51、Windows SDK 10.0.26100.0 で確認しました。数値比較は Release、D3D12 デバッグレイヤー有効で実行しています。

## 固定構成との一致

元のソースを変更せずに比較用実行ファイルへコンパイルし、Hillaire2020 / C+A+B / SH L2 + ground / RGB Mean / Per Pixel / Sun disk 有効を両実装に設定しました。

23シナリオ × FP32 / FP16 の46ケース、506項目すべて合格しました。空と地表を分け、LUT、AP の3成分と平均透過率、天空照度、最終シーンカラーを比較しています。深度は完全一致、固定データの位相関数モーメント9値も float のビット列が一致しました。

| 形式 | 最大の正規化 RMSE | 基準 | 最大の正規化絶対差 | 基準 |
|---|---:|---:|---:|---:|
| FP32 | 1.571×10⁻⁵ | ≤ 10⁻⁴ | 4.237×10⁻⁴ | ≤ 10⁻³ |
| FP16 | 5.363×10⁻⁵ | ≤ 10⁻³ | 9.542×10⁻⁴ | ≤ 10⁻² |

RMSE は参照値の RMS、最大絶対差は参照値の最大絶対値で正規化しています。許容差は計画値から変更していません。NaN / Inf はありません。

シナリオには太陽天頂角45° / 80° / 88°、地上2 m / 高度3 km、太陽側 / 反対側、AOD 0.001 / 0.1 / 1、地表アルベド0 / 0.3 / 1、照度0、露出変更、太陽ディスクサイズ変更、影マップなし、近景の影、濃い大気と地表アルベド1の組み合わせを含みます。代表画像を GT7 SDR で変換して目視でも比較しました。

削除した機能によるコンパイラー最適化の差を許容差内で確認したもので、大気モデルの絶対精度を新たに保証する検証ではありません。RGB Mean と SH 近似の既知の誤差は元の構成と同じです。

## 更新・リソース寿命・サンプル

- LUT サイズと各積分設定の最小・既定・最大、サイズ変更の繰り返しで有限な出力を確認。Per Pixel の探索数・二分探索数を変えた合成も実行。
- 無変更・照度・ディスクサイズ変更で媒質 LUT が再生成されないこと、地表アルベドで多重散乱だけ、AOD で透過率と多重散乱が更新されることを確認。
- AP サイズだけの変更で媒質 LUT が再生成されないこと、不正な品質設定が既存リソースを変更しないことを確認。
- 非表示サンプルで8フレームの LUT サイズ変更、ウィンドウリサイズ、SDR / HDR10 の反復切り替えを実行。実機は HDR10 を利用でき、OS 報告のピークは約1107 nit。
- D3D12 の corruption / error メッセージは0件。UI は描画しており、マウスによる個々のスライダー操作の手動確認は未実施です。
- Terrain / Spheres の個別切り替え追加後も Release をビルドし、両方表示・地形のみ・球のみ・両方非表示の4通りを smoke で実行。切り替え時には広域シャドウマップも更新し、D3D12 エラーがないことを確認しました。
- 固定データの再生成はバイト単位で一致。

## 既存の検証版

既存のソース、シェーダー、係数データ、CMake、検証スクリプトは変更していません。

変更前後に現行 Release をビルドして14種のバッチを実行し、**989個の EXR が画素単位で完全一致**しました。比較は `reference/compare_dumps.py --tol 0`。既存の SH モーメント検証も8件すべて合格しています。

対象は Transmittance、単散乱、多重散乱、Sky LUT、太陽近傍、分光、AP、AP 透過率、天空照度、地表の影、AP の影、AP 影方式比較、全エアロゾルプリセット、SH 多重散乱です。全ての物理精度検証スクリプトやパストレースの再評価を実施したわけではなく、既知の不合格の基準も変更していません。

## 独立性と規模

`compact/` を別のソースディレクトリへコピーし、比較ツールを無効にした通常構成で Debug / Release をビルドしました。依存パッケージは既存の vcpkg インストールを明示して再利用しています。元の係数 JSON と検証版のソースを通常ビルド・実行時に読みません。サンプルなしのライブラリ構成では ImGui / JSON の検索を要求しません。

| 対象 | 検証版 | コンパクト版 |
|---|---:|---:|
| 大気 C++（ヘッダー含む） | 1621行 | 559行 |
| 大気 HLSL / HLSLI | 2585行 | 1188行 |
| 上記合計 | 4206行 | 1747行（約58%削減） |
| 大気用シェーダーバイナリの種類 | 26 | 7 |
| Renderer が所有する LUT / ボリューム | 12枚 | 8枚 |
| 天空照度バッファ | 1本 | 1本 |

行数は空白・コメントを含む物理行数で、生成した `FixedData.h`、データ、GPU 補助コード、サンプル、比較ツールを除きます。コンパクト版の位相関数バッファは別に1本です。検証版の全プリセット分の位相関数管理は移植対象に含めていません。

リポジトリ内の詳細な出力先：

- `dumps/compact_baseline_before` / `dumps/compact_baseline_after`：既存版の回帰比較。
- `dumps/compact_compare_v3/reference`：変更していない既存ソースからの参照出力。
- `dumps/compact_compare_packaged/compact` / `dumps/compact_compare_packaged/report.json`：最終版の出力・506項目の結果。
- `build/standalone-check`：フォルダ単位のコピーによるビルド・起動確認。

上記の大きなダンプとビルド成果物はこの移植用フォルダには同梱しません。比較ツールで再生成できます。
